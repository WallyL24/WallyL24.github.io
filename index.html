Software Design and Engineering

This artifact demonstrates my software design and engineering skills through the enhancement of a thermostat control system originally developed in CS 350: Emerging Systems Architectures and Technologies.

The original project was designed to simulate the behavior of a thermostat by reading temperature data from a sensor, switching between states such as off, heat, and cool, and displaying system information on an LCD screen. It also uses LEDs to indicate system activity and sends updates through serial communication. While the original version functioned correctly, the overall structure of the code made it difficult to maintain and expand.

I chose this artifact for my ePortfolio because it demonstrates my ability to integrate both hardware and software while applying core software engineering principles. In the original implementation, most of the functionality was handled in a single structure, including temperature readings, system logic, LED control, and display updates.

For the enhancement, I reorganized the program into separate components to improve modularity and maintainability. I created a TemperatureSensor class to handle sensor input, a ManagedDisplay class for LCD output, an LEDController class for LED behavior, and a SerialReporter class for communication. The Thermostat class was then simplified to focus only on managing system states and logic. This redesign made the program easier to read, test, and expand in the future.

The improvements I made align with the course outcomes identified earlier in the course. I demonstrated Course Outcome 3 by redesigning the system to improve efficiency and maintainability through better software design practices. I also demonstrated Course Outcome 4 by applying appropriate tools and techniques, including the use of a state machine and hardware integration, to improve the system’s functionality. In addition, I made progress toward Course Outcome 5 by incorporating basic error handling for the sensor and serial communication, which helps ensure the system can handle unexpected issues more reliably.

Through this enhancement, I learned the importance of proper code organization and modular design. Although the original system worked, breaking the application into smaller, focused components made it much easier to manage and understand. One of the biggest challenges was restructuring the code without introducing new errors, especially when separating functionality into different classes. This required careful testing and debugging to ensure the system continued to function as expected.

Algorithms and Data Structures

This artifact is a client service management program originally developed in CS 410. The purpose of the original project was to manage customer service selections and display information based on user input. I selected this artifact because it gave me the opportunity to improve a simple program by adding stronger data organization and more efficient logic.

The enhancement focused on implementing better data structures and improving the way information was stored and processed. Instead of using separate variables for each client, I redesigned the program to use a vector of client objects. Each object stored client information such as name and selected service. This allowed the program to manage multiple records more efficiently and made the code easier to scale if more features were added later. Through this enhancement, I demonstrated problem solving, algorithmic thinking, and the ability to choose appropriate data structures for a solution.

While completing this enhancement, I learned how important it is to plan data organization before writing the rest of the program. A challenge was restructuring older code so it could work with the new data model. Once completed, the program became cleaner, easier to maintain, and more realistic for real-world use. This artifact reflects my growth in analyzing code and improving efficiency through better design choices.

This enhancement aligns with Course Outcome 3 by improving the program through better data structures and more efficient organization of information. It also supports Course Outcome 4 through the use of appropriate programming tools and techniques to create a more scalable and maintainable solution.

Databases

This artifact is a weight tracking mobile application originally developed in CS 360, Mobile Architecture and Programming. The application allowed users to create accounts, log in, and store daily weight entries using SQLite. I selected this artifact because it demonstrates database design, mobile development, and user-focused software solutions.

The enhancement focused on improving the database functionality and making stored information more useful to the user. I updated the schema and retrieval methods to better organize historical records and support trend analysis. I also improved queries used to display past weight entries more clearly and efficiently. These changes made the application more practical by turning stored data into meaningful progress tracking information. Through this enhancement, I demonstrated database management, application design, and problem solving skills.

During this process, I learned that a database should do more than simply store information. It should help users understand and benefit from their data. One challenge was balancing simplicity with useful features, but by refining queries and structure, I created a stronger final product. This artifact demonstrates my ability to improve data-driven applications and apply database concepts in a practical environment.

This enhancement aligns with Course Outcome 3 by improving the design of a data-driven application to better solve user needs. It also supports Course Outcome 4 through the implementation of database tools and application improvements. In addition, it demonstrates progress toward Course Outcome 5 by emphasizing secure handling of user account and stored data.
